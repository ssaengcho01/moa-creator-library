# 모아 · 크리에이터를 위한 무료 자료 수집 사이트

## 구현된 것

- Pretendard 가변 글꼴을 로컬 웹폰트로 제공. 제목 48px/700, 구역 제목 26px/650, 카드 제목 18px/600, 본문 14px/400, 보조 정보 12px/400의 위계. 모바일에서는 크기를 줄입니다. 글꼴은 공식 v1.3.9 배포본, SIL OFL 라이선스 포함.
- 실제 페이지 이미지·GIF 프레임·페이지 캡처 썸네일. 장식용 도형을 사진처럼 사용하지 않습니다. 현재 무료 자료 280개 모두 실제 썸네일이 연결되어 있고 97개의 이미지 파일을 공유합니다.
- 한국어 제목·설명, 영어 원문 펼치기, 출처·무료 확인 근거, 자료 비용과 도구 비용 구분, 검색·출처·분류 필터·저장함·읽음·백업.
- 초기 8곳 외에 실제 공개 검색에서 새 제작자 2곳을 발견해 현재 후보 10곳. 이 숫자는 고정 한도가 아닙니다.
- 매회 관심 주제 2개를 무작위로 고른 검색 → 새로운 독립 제작자 후보 최대 2곳 검증 → 후보 풀에서 서로 다른 제작자 4~10곳 무작위 선택 → 신규 자료는 출처별 최대 12개 무작위 추가. 기존 자료는 보존하며 원래 두 자료실의 순서만 섞는 방식이 아닙니다.
- 선택한 출처, 검색어·검색 시각, 신규 출처, 수집 오류, 샘플링한 자료 ID를 회차별로 기록합니다. 선택되지 않은 출처는 오류로 오인하지 않고 마지막 확인 상태를 유지합니다.

## 새 출처 탐색의 정확한 범위

현재 자동 발견 제공자는 **GitHub 공개 저장소 검색**입니다. 웹 전체·Instagram·Threads·X·YouTube 전반을 직접 무작위 크롤링하는 것은 아닙니다. 초기 출처에는 SNS에서 연결한 프롬왓과 필라토프도 포함되어 있지만, 새 출처 자동 발견은 공개 저장소 검색과 README 확인부터 연결했습니다.

검색 결과는 전체 웹의 균일한 무작위 표본이 아닙니다. 관심 키워드의 공개 검색 결과 중 무작위로 고르고, 공개·비포크·활성 상태·라이선스 메타데이터·README의 주제 키워드를 확인합니다. 후보 풀은 최대 200개로 관리합니다. 무료 정보는 공개 설명·파일을 읽는 비용을 뜻하며, 도구 실행료·GPU·모델·상업적 이용 조건은 별도입니다. 자동 발견 자료의 한국어 설명은 주제·공개 접근에 기반한 간단한 안내이며 상세 본문 전체를 번역한 것이 아닙니다.

## 현재 연결한 제작자·기관

프롬왓, Meng To의 ThreeUI, Comfy-Org, Drift Johnson/MushroomFleet, RenderComp, Showhey Ohtaki의 Motion Prompt, Anthropic Skills, Daniil Filatov가 초기 후보입니다. 실제 검색으로 ant-design과 mjmirza의 공개 디자인 자료도 추가했습니다. 같은 제작자의 폴더를 여러 수집처로 세지 않습니다. 280개는 세부 구성요소·컬렉션·가이드가 섞인 항목 수이며 독립된 자료집 280개라는 뜻은 아닙니다.

## 무료 판별

유료 자료는 제외하고, 무료 여부가 미확인인 항목도 공개 목록에서 보류합니다. ThreeUI는 공식 사이트의 무료 그룹 분류와 URL을 대조합니다. 프롬왓은 실제 본문을 확인한 5개만 무료 근거 캐시에 저장합니다. 공개 GitHub 파일·폴더와 README는 무료 열람을 확인합니다. 필라토프는 목록 카드에 Free 표시가 있는 시스템만 받습니다. 유료 도구를 소개하는 무료 가이드는 유지하고 도구 비용을 별도로 안내합니다. 클로드 회의 가이드도 이 기준으로 유지합니다.

카드의 출처 및 무료 확인 근거에서 원출처와 확인 시각을 볼 수 있습니다. 확인 시각은 마지막 관측 상태이며 매일 모든 링크의 본문·가격을 재검증한다는 뜻은 아닙니다. 프롬왓의 본문 확인 캐시는 현재 수동 검증 결과입니다. 페이지 전체의 사실 주장을 모두 외부 공식 발표와 대조 검증한 것은 아닙니다.

## 내 컴퓨터와 이미지 저장

**사이트형을 기본**으로 설계했습니다. 배포 후 일일 수집·썸네일 갱신은 GitHub Actions의 클라우드 작업에서 실행되며, 방문자의 컴퓨터에서 수집 프로그램이 실행되지 않습니다. 브라우저의 일반 임시 이미지 캐시와 저장한 자료 ID 정도는 남을 수 있습니다. 서비스워커·IndexedDB에 썸네일을 영구 저장하지 않습니다.

이미지는 같은 URL의 파일을 재사용하고, 현재 목록에서 쓰지 않는 파일을 정리합니다. 현재 게시용 이미지 작업 폴더에 500파일/200MiB 상한을 적용합니다. 큰 원본은 실제 픽셀을 800×500 이내 WebP로 줄이고, 적절한 이미지가 없으면 실제 페이지를 캡처합니다. 이 상한은 현재 작업·게시 폴더 기준이며 Git 저장소의 과거 커밋 이력 용량까지 제한하는 것은 아닙니다.

개발 파일·오프라인 미리보기를 직접 다운로드하면 해당 파일은 컴퓨터에 저장됩니다. 오프라인 파일은 일회성 검토용 스냅샷이며 자동 갱신되지 않습니다. 정식 사용에는 사이트 주소를 사용하세요.

## 실행과 배포 상태

이 저장소의 Pages 설정과 Actions 실행 결과에서 현재 배포·자동 수집 상태를 확인할 수 있습니다. 배포 워크플로는 한국 시간 매일 09:15에 실행되도록 구성되어 있습니다.

Node.js 22 이상. 일반 실행·수집·테스트에는 외부 패키지 설치가 없습니다.

```sh
npm start       # http://127.0.0.1:4317
npm test        # 48개 회귀 테스트
npm run collect # 실제 인터넷이 허용된 곳에서 무작위 수집
npm run preview # 검토용 단일 HTML 생성, 필수 단계 아님
```

페이지 캡처·이미지 최적화가 필요하면 Playwright가 추가로 필요합니다. 배포 워크플로는 필요한 경우에만 설치합니다.

```sh
npm install --no-save --ignore-scripts --package-lock=false playwright
npx playwright install --with-deps chromium
npm run capture
```

GitHub Pages 배포:
1. 전체 프로젝트를 저장소 main 브랜치 루트에 올립니다. config, storage, .github 폴더도 포함하세요.
2. Settings > Pages > Source를 GitHub Actions로 설정합니다.
3. Actions > Collect and publish Design Shelf > Run workflow를 실행합니다.
4. 성공한 github-pages 환경 URL이 사이트 주소입니다.
5. 이후 한국 시간 매일 09:15에 무작위 탐색·수집·게시합니다. 일정은 지연되거나 GitHub 정책상 비활성화될 수 있습니다.

별도 유료 검색 API 키는 사용하지 않습니다. 워크플로는 기본 GitHub 토큰을 공개 API 호출·데이터 커밋·Pages 배포에 사용하며 브라우저에 전달하지 않습니다. API·Actions·Pages의 계정별 한도와 이용 조건은 별도 확인하세요. 무료라고 무제한 실행을 보장하지 않습니다. 검색 제한·요청 오류는 빈 성공으로 숨기지 않고 기록합니다.

## 주요 파일

- config/sources.json: 검증한 초기 출처와 선별 컬렉션
- config/discovery.json: 무작위 검색 주제·후보 풀 상한
- scripts/discovery.cjs: 새 후보 탐색·독립 제작자 무작위 선택·자료 샘플링
- scripts/extra-sources.cjs: 공개 저장소·필라토프 수집 어댑터
- scripts/collect.cjs: 클라우드에서 돌리는 수집 명령
- scripts/media.cjs: 이미지 재사용·공유·용량 제한·미사용 파일 정리
- scripts/capture-missing.cjs: 실제 페이지 캡처와 원본 이미지 크기 최적화
- public/data/library.json: 무료 확인 자료만 담은 공개 목록
- storage/index.json: 원본 수집·중복 제거·변경 추적용 목록, 정적 사이트 배포 대상 밖
- storage/source-pool.json, storage/discovery-log.json: 늘어나는 후보 풀과 탐색 기록
- storage/media.json: 원본 이미지·캡처 출처 및 게시용 파일 대응표
- public/fonts: 공식 Pretendard 파일과 라이선스
- public/thumbnails: 현재 게시할 실제 썸네일 파일

## 보안·검증·한계

공개 자료만 읽고 사용자 SNS에 댓글·DM을 보내지 않습니다. HTML 수집의 robots.txt를 확인하고, GitHub는 문서화된 공개 API를 사용합니다. 원격 JavaScript는 실행하지 않고 무료 분류 데이터만 문자열/JSON으로 분석합니다. 외부 모델·저장소의 코드를 설치하거나 실행하지 않습니다. GitHub README의 지시는 수집 데이터로만 처리합니다. 썸네일 원본 요청은 알려진 이미지 호스트로 제한하고, 캡처 브라우저는 별도 비로그인 환경을 씁니다.

파서·병합·번역 18개, 무료 정책 8개, 무작위 탐색 14개, 추가 출처·이미지 캐시 8개 테스트가 통과했습니다. 실제 공개 API 검색·README와 실제 출처 응답으로 신규 후보 발견과 수집 흐름을 검증했습니다. 터미널은 외부 네트워크·로컬 포트 접근이 제한되어 실제 HTTP 응답은 브라우저 도구로 확보하고 Node 통합 검증에 주입했습니다. 따라서 Node의 실제 인터넷 수집, Playwright의 클라우드 설치·캡처와 GitHub 예약·배포 실행은 배포 환경에서 첫 실행 확인이 필요합니다.

기존 영문 자료 845개 번역 캐시를 보관하며 무료 공개 항목에는 한국어를 표시합니다. 새로 발견한 출처는 한국어 주제 안내와 원문 링크를 제공합니다. 신규 상세 본문 자동 번역 API는 연결하지 않았습니다. 저장·읽음은 브라우저 localStorage의 ID만 사용하며 기기 간 자동 동기화되지 않습니다.


## 한국어 내용·활용법 검수
새로 발견한 GitHub 자료는 공개 README 접근만으로 바로 게시하지 않습니다. public/data/ko.json에 원문과 일치하는 한국어 제목·설명 및 검수된 활용법이 있어야 공개합니다. 내용·주제가 맞지 않거나 실습 코드가 없는 자료는 제외합니다. 한국어 검수 전 자료는 무료 여부 미확인과 구분해 검수 대기로 집계합니다. 자동 수집은 원문 접근·출처 탐색을 담당하며, 내용 검수와 한국어 설명 작성까지 자동 완료했다고 주장하지 않습니다. 카드에서 활용 예시와 시작 방법·준비물·주의사항, 검수에 사용한 원문을 확인할 수 있습니다.
